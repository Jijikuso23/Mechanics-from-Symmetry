# Mechanics from Symmetry

## 対称性と作用原理から力学を構成する

### ― Newton力学から特殊相対論へ ―

作用原理と時空の対称性を出発点として、Newtonの運動方程式を前提とせずに古典力学を構成することを目的としたノートです。

解析力学を単なるNewton力学の書き換えとしてではなく、**作用原理と対称性から物理法則を構成する枠組み**として理解することを目指しています。
